# AniBare

An absolutely bare bones anime website. Heavily inspired by [pystardust/ani-cli](https://github.com/pystardust/ani-cli).

## Run Locally

**Clone the project**

```bash
git clone https://github.com/yudin101/anibare.git
```

**Go to the project directory**

```bash
cd anibare
```

**Install dependencies**

```bash
npm install
```

**Setup environment vairables**

```bash
echo "NODE_ENV='development'" > .env
echo "FRONTEND_URL='https://frontend.url'" >> .env
echo "SERVER_URL='https://server.url'" >> .env
echo "SERVER_PORT=server_port" >> .env
```

**Start the development server**

```bash
npm run dev
```
